# WartoWracać

Elektroniczne karty lojalnościowe dla firm: salony beauty, fryzjerzy, paznokcie, barberzy, bistro i restauracje.

- `index.html` – karta klienta (`?l=adres-lokalu`)
- `panel.html` – panel lokalu (pieczątki, klienci, nagrody, ustawienia, zespół)
- `admin.html` – administracja usługi
- `supabase/schema.sql` – baza danych (Supabase)

Szczegóły uruchomienia: `INSTRUKCJA.md`.
